Long Form Studio

A private production tool for the YouTube channel Animated Archives.

What it is

Long Form Studio is an application that runs on the computer of the creator of the YouTube channel Animated Archives. It helps the creator make long, narrated history videos: writing and editing the script, recording the narration, creating illustrations, editing the video, and preparing the title, description and thumbnail.

It is a personal tool. It is not offered to the public and there is no sign-up: the only person who uses it is the creator of the channel, with their own Google account.

How it uses Google and YouTube

When the creator links their YouTube channel, Long Form Studio uses YouTube API Services to:

  • read the ID and name of the linked channel, to show which channel is connected;
  • upload the finished videos to that channel, with their title, description and tags;
  • set the thumbnail of the uploaded videos.

It does not read, change or delete anything else on the channel or in the Google account. See the privacy policy for what is stored and how to revoke access.
