Privacy Policy

Long Form Studio · last updated 27 September 2026

Long Form Studio is a private production tool that runs on the computer of the creator of the YouTube channel Animated Archives. This policy explains which Google user data it uses and how.

YouTube API Services

Long Form Studio uses YouTube API Services. By linking a YouTube channel to Long Form Studio, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

When a YouTube channel is linked, Long Form Studio asks Google for permission to:

  • View the YouTube account (youtube.readonly): only used to read the ID and name of the linked channel;
  • Upload videos (youtube.upload): used to upload finished videos with their title, description, tags and thumbnail.

No other data from the Google account or the YouTube channel is read, such as comments, subscribers, analytics, e-mail or contacts.

How the data is used

The data is used only to upload the creator's own videos to the creator's own channel and to show which channel is linked. It is not used for advertising, it is not sold, and it is not shared with anyone.

Where the data is stored

Long Form Studio has no servers. The OAuth token that lets it upload, and the ID and name of the linked channel, are stored only in a local database on the creator's own computer. There are no user accounts, cookies or analytics.

Revoking access and deleting data

Choosing "Ontkoppelen" (unlink) in Long Form Studio revokes the token at Google and deletes the token and the channel details from the local database right away. Access can also be revoked at any time on the Google security settings page.

Google API Services User Data Policy

Long Form Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
